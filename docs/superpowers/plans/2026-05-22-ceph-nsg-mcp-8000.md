# Ceph NSG MCP 8000 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open `TCP/8000` for Ceph lab MCP access from trusted source CIDR and make it persistent in Ceph Bicep IaC.

**Architecture:** Apply a two-phase change: first patch runtime Azure NSG (`mansion-ceph-nsg`) so current environment becomes reachable immediately; then codify the same rule in `storage/3node-ceph/iac/modules/nsg.bicep` and related docs so rebuilds preserve behavior. Keep source scope restricted to existing `allowedSourceCidr` and avoid broad internet exposure.

**Tech Stack:** Azure Resource Graph / Azure networking (NSG), Bicep IaC, Markdown docs.

---

### Task 1: Update live Azure NSG inbound rule

**Files:**
- Create: None
- Modify: Azure resource `Microsoft.Network/networkSecurityGroups/mansion-ceph-nsg` in RG `MANSION_CEPH_RESOURCE`
- Test: Query output from Azure Resource Graph (`execute_query`)

- [ ] **Step 1: Confirm current inbound rules before change**

Run query:

```kusto
Resources
| where type =~ 'microsoft.network/networksecuritygroups'
| where resourceGroup =~ 'MANSION_CEPH_RESOURCE' and name =~ 'mansion-ceph-nsg'
| mv-expand rule = properties.securityRules
| project ruleName=tostring(rule.name), priority=toint(rule.properties.priority), access=tostring(rule.properties.access), protocol=tostring(rule.properties.protocol), src=tostring(rule.properties.sourceAddressPrefix), dstPort=tostring(rule.properties.destinationPortRange)
| where tostring(rule.properties.direction) =~ 'Inbound'
| order by priority asc
```

Expected: no `dstPort == "8000"` allow rule.

- [ ] **Step 2: Add NSG rule for MCP**

Apply rule:

```bash
az network nsg rule create \
  --resource-group MANSION_CEPH_RESOURCE \
  --nsg-name mansion-ceph-nsg \
  --name AllowMCP8000 \
  --priority 210 \
  --direction Inbound \
  --access Allow \
  --protocol Tcp \
  --source-address-prefixes 61.216.143.3/32 \
  --source-port-ranges '*' \
  --destination-address-prefixes '*' \
  --destination-port-ranges 8000
```

Expected: command succeeds and rule appears in NSG.

- [ ] **Step 3: Verify live rule exists and is scoped correctly**

Run query:

```kusto
Resources
| where type =~ 'microsoft.network/networksecuritygroups'
| where resourceGroup =~ 'MANSION_CEPH_RESOURCE' and name =~ 'mansion-ceph-nsg'
| mv-expand rule = properties.securityRules
| where tostring(rule.name) == 'AllowMCP8000'
| project ruleName=tostring(rule.name), priority=toint(rule.properties.priority), access=tostring(rule.properties.access), protocol=tostring(rule.properties.protocol), src=tostring(rule.properties.sourceAddressPrefix), dstPort=tostring(rule.properties.destinationPortRange), direction=tostring(rule.properties.direction)
```

Expected: one row, `access=Allow`, `protocol=Tcp`, `src=61.216.143.3/32`, `dstPort=8000`, `direction=Inbound`.


```bicep

  properties: {

    destinationPortRange: '8000'
```
